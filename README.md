# GameTracker — Система батьківського контролю та ліміту ігор для Windows

Надійний фоновий сервіс та CLI-утиліта для Windows, що контролює загальний ігровий час (за замовчуванням 2 години на добу), видає завчасні сповіщення (за 5 та 1 хвилину), блокує запущені та нові ігри до опівночі (00:00) та захищений від обходу (переводу годинника, фальсифікації таймзон, перезавантаження ПК).

---

## 🚀 Основні можливості

1. **Глобальний добовий ліміт (120 хвилин)**:
   - Облік ведеться сумарно для всіх ігор (якщо зіграно 1 год в одній та 1 год в іншій — ліміт вичерпано).
   - При паралельному запуску кількох ігор час не подвоюється (інваріант конкурентності).
   - Автоматичне скидання ліміту о 00:00 (північ) за місцевим часом.

2. **Гібридне детектування ігор**:
   - **Автовиявлення лаунчерів**: автоматично сканує каталоги та маніфести бібліотек Steam (`libraryfolders.vdf`), Epic Games Launcher (`*.item`), GOG Galaxy та Xbox Games (`XboxGames`).
   - **Вбудований чорний список**: включає популярні автономні/мережеві ігри (`cs2.exe`, `dota2.exe`, `valorant.exe`, `robloxplayerbeta.exe`, `minecraft.exe`, `genshinimpact.exe`, `gta5.exe` тощо).
   - **Білий список винятків**: захищає системні процеси та оболонки (`explorer.exe`, `taskmgr.exe`, лаунчери `steam.exe` тощо).

3. **Завчасні сповіщення та SLA завершення процесів**:
   - Сповіщення через нативні Windows Toast Notifications за 5 хвилин та 1 хвилину до блокування.
   - Миттєва термінація (`TerminateProcess` / `taskkill`) активних ігор за <2 с при досягненні 120 хвилин.
   - Постійне відстеження під час блокування: будь-яка спроба запустити гру до 00:00 примусово закривається за <2 с.

4. **Захист від обходу (Parental Control & Anti-Tamper)**:
   - **Монотонний таймер (`GetTickCount64`)**: запобігає обходу через переведення системного годинника назад або поступовий дрифт уперед (`cumulative forward creep`).
   - **Захист від зміни таймзони**: перевірка часових меж не дозволяє зняти блокування штучною зміною часового поясу.
   - **Криптографічна цілісність (HMAC-SHA256)**: стан (награні секунди, дата, статус блокування) зберігається атомарно з резервною копією (`state.json.bak`) та перевіркою чексумів.
   - **Майстер-пароль**: конфігурація та аварійне розблокування захищені PBKDF2-HMAC-SHA256 хешуванням із сіллю.

## 🛠️ Встановлення та запуск

Вимоги: Windows 10/11, Python 3.10+ (всі модулі використовують нативні Win32 API через ctypes, сторонні pip-пакети не потрібні).

### 1. Перевірка статусу
```bash
python -m gametracker.cli status
```

### 2. Встановлення батьківського пароля
```bash
python -m gametracker.cli set-password
```

### 3. Перегляд та налаштування списку ігор
```bash
# Переглянути список
python -m gametracker.cli list-games

# Додати власну гру
python -m gametracker.cli add-game my_game.exe

# Видалити гру
python -m gametracker.cli remove-game my_game.exe
```

### 4. Запуск сервісу в консолі (для тестування)
```bash
python -m gametracker.cli run
```

### 5. Реєстрація автозапуску у Windows (як системне завдання від імені SYSTEM)
Запустіть термінал PowerShell / CMD **від імені Адміністратора**:
```bash
python -m gametracker.cli install-task
```
*Завдання `GameTrackerService` запускатиметься автоматично при старті комп'ютера з найвищими привілеями.*

Щоб видалити завдання:
```bash
python -m gametracker.cli uninstall-task
```

### 6. Аварійне розблокування (вимагає пароль)
```bash
python -m gametracker.cli unlock
```

## 📦 Встановлення як звичайної програми (Windows Setup .exe)

### Спосіб 1: Готовий інсталятор з GitHub Releases (Рекомендовано)
У репозиторії налаштовано **GitHub Actions CI/CD** ([`.github/workflows/build-release.yml`](.github/workflows/build-release.yml)):
1. При кожному релізі / оновленні версії GitHub автоматично компілює автономні бінарники за допомогою PyInstaller та пакує їх у стандартний інсталятор Windows через Inno Setup.
2. Користувач завантажує файл `GameTracker_Setup_v1.0.0.exe` зі сторінки **Releases** на GitHub.
3. Запускає інсталятор як звичайну програму (Next → Install).
4. Інсталятор автоматично:
   - Встановлює програму у `C:\Program Files\GameTracker\`.
   - Реєструє та запускає фонову службу Windows з правами `SYSTEM`.
   - Створює ярлики в меню Пуск ("GameTracker Status", "GameTracker Set Password").

### Спосіб 2: Локальне встановлення в 1 клік (`build_and_install.bat`)
Якщо ви клонували репозиторій локально:
1. Клацніть правою кнопкою миші на [`build_and_install.bat`](build_and_install.bat) → **"Запустити від імені адміністратора"**.
2. Скрипт автоматично скомпілює `.exe`, встановить службу у `C:\Program Files\GameTracker\` та запустить її.
3. Для чистого видалення запустіть [`quick_uninstall.bat`](quick_uninstall.bat).

## 🧪 Запуск тестів

Репозиторій містить повний набір автоматизованих тестів (65 тестів, час виконання ~8 с):
```bash
python -m unittest discover tests
```

Перевірено:
- `test_accumulation.py`: ліміти, акумуляція кількох ігор, інваріантність паралельних сесій.
- `test_anti_tamper.py`: перевірка відкатів часу, дрифту, `GetTickCount64`.
- `test_persistence.py`: атомарність запису, резервне копіювання, валідація схем.
- `test_adversarial_stress.py`: стрес-тести атак на годинник, зміщення дат, збої файлової системи.
- `test_detector_and_cli.py`: предикати визначення ігор, хешування паролів, збереження конфігів.
- `test_e2e_full_lifecycle.py`: повний наскрізний життєвий цикл від 0 до 120 хв з блокуванням і опівнічним скиданням.
